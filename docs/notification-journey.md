# 0.8.0 手机通知与腕上核对

点击手机声音通知可直接查看那一条提醒的时间、场景和反馈状态。有多条提醒时，先点较早的一条也能单独确认。打开详情本身不提交反馈。提醒记录已清空或超过 100 条保留范围时，详情会显示原因。

在「设置权限与手表」选择敲门、门铃或闹钟。页面显示当前场景下该类别的手机通知和振动设置，可直接打开系统对应通道。发送测试后，在腕上看到相应标题再点「我在手表上看到了」。三类声音各自保留最后一次确认时间。升级前通过引导确认的测试计入敲门。

首页仍显示最近一次人工确认的时间。「提醒记录」支持只看待反馈的真实提醒，便于把真实识别和设备测试分开查看。

## 一轮集中验收

| 操作 | 预期观察 |
|---|---|
| 在手表引导分别发门铃与闹钟测试，只确认实际在腕上看到的一类 | 两个标题不同，只有手动确认的类别更新日期。 |
| 先切到学习场景并发敲门测试，再切回居家并发门铃测试。点手机较早的敲门通知 | 详情是学习场景敲门。检查通知设置应打开学习敲门通道。确认后，门铃仍可独立反馈。 |
| 记录页启用「只看待反馈的真实提醒」，在监听中真实敲门，再在腕上点「已看到」 | 模拟事件被滤去。手机收到腕上操作后，对应真实提醒从筛选结果移出，取消筛选后仍可查看。 |
| 在表端临时关掉声境通知同步，再发送新的测试，恢复开关后重测 | 人工按腕上实际观察确认。既有确认时间仅说明上一次成功。 |

本包同时包含 [锁屏半小时与中断恢复验收](listening-recovery.md)。测试应记录腕上实际结果，手机发起通知不能证明腕上送达。
