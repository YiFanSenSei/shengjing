# C、A、D 的提醒规则约定

更新：2026-11-28 · 基线 0.10.0

C 负责“这个声音此刻要不要提醒”。输入是三类模型分数、时间、场景和用户设置；输出只有两种：提醒，或不提醒并给出原因。这一页固定原因名称、三种失败情形的说法和现场记录方式。A 按这里显示，D 按这里记现场，C 按这里回放。规则有改动时先改这一页和[场景与偏好回放](policy-replay.md)，再改代码。

## 原因名称

| 代码 | 手机显示 | 含义 |
|---|---|---|
| `new_event` | 已请求提醒 | 达到阈值，且不在同一串声音、冷却、关闭或暂停中 |
| `below_threshold` | 低于阈值 | 分数不到当前阈值；标准敲门/闹钟 0.60，增强 0.40，门铃始终 0.60 |
| `same_event` | 连续事件，避免重复 | 与上一次同类声音相隔不超过 2.5 秒，视为同一串 |
| `cooldown` | 提醒冷却中 | 距上一次提醒还没到本场景、本声音的最短间隔 |
| `disabled` | 类别已关闭 | 用户关闭了该类声音 |
| `quiet_mode` | 真实提醒已暂停 | 用户暂停了真实提醒；模拟按钮不受影响 |
| `invalid_event` | 无有效结果 | 时间倒退或输入无效；正常监听中不应出现 |

## 三种情形

1. **听错**：实际是敲门，手机报成门铃，或用户点“声音认错了”。归 B 的识别问题，不计入 C 的间隔效果。
2. **听对但不想**：类别对，用户仍点“提醒太频繁”或明确说不想被打扰。归 C 的场景、间隔和偏好。
3. **该提醒却没提醒**：真实声音发生了，手机没有提醒。可能来自识别分数不够、同一串合并、冷却、类别关闭、暂停或系统阻止。D 的现场真值负责发现“漏了”；只有策略原因记录才能分清是冷却还是分数不够。没有记录时写“不可归因”，不猜。

## 现场字段怎么对上

D 的手机文件 `shengjing.phone.v1` 当前只有序号、相对时间、场景、类别和通知状态；观察文件 `shengjing.observer.v1` 有真实声音区间和腕上观察。两者能算“提醒了多少、漏了多少、腕上到没到”，但看不出“为什么没提醒”和“用户是否嫌频繁”。

建议 A 在 `shengjing.phone.v1` 中增加可选字段，不升版本，D 的脚本忽略不认识的字段：

- 每条提醒加 `score`（0 到 1）和 `feedback`（pending / ack / false_alarm / too_frequent / ack_too_frequent）。
- 再加一个有上限的 `suppressed` 列表，只记真实候选的类别、原因、相对时间和分数，录音一律不导出。上限 200 条，超过后保留最近的。

这样 C 才能在现场把“冷却压掉”和“识别没到阈值”分开。A 实现前，现场只能靠诊断页当场看原因，事后标“不可归因”。

## 固定规则

- 场景由用户手动选择，不做自动识别。居家和学习只改敲门间隔，门铃和闹钟保持 15 秒。
- 同一串声音 2.5 秒内合并；切换场景不会清空上一串和上一次提醒时间。
- 默认最短间隔：居家敲门 15 秒，学习敲门 60 秒，门铃 15 秒，闹钟 15 秒。
- 同一场景、同一类敲门或门铃累计两次有效“太频繁”反馈后，记录页给一次建议。采纳后居家敲门 60 秒、学习敲门 120 秒、门铃 60 秒；闹钟不能采纳。选择“保留”也重新计数。
- 偏好只作用于所选场景和声音，重启后保留；清空历史会删掉建议依据，但已采纳的间隔保留，恢复入口仍在。
- 暂停和关闭类别优先于场景；增强模式只改阈值，不改间隔和去重。

## 指标

- 需要提醒命中 / 需要提醒总数。
- 额外提醒次数（不想要的同类提醒），按小时报告时写清有效观察时长。
- 被策略跳过的需要提醒：分别记 `cooldown` 和 `same_event`。
- 听错次数、听对但不想次数。
- 建议出现、采纳、保留、恢复的次数。
- 用户能否说清“拉长间隔会减少重复打扰，但可能漏掉下一位来客”。

## 已知代价

学习场景的 60 秒（采纳后 120 秒）会把间隔内的下一位来客一起挡掉。这不是 bug，是“少打扰”换来的代价，必须在演示和比赛材料里明说，不能用自动场景或更低阈值掩盖。样本少时只报次数和分母，不报百分比外推。

## 现场记录顺序

1. D 先记真实声音的开始和结束，A 再导出手机文件。
2. C 看诊断页的原因，逐条标“听错 / 冷却 / 同一串 / 关闭 / 暂停 / 分数不够 / 不可归因”。
3. 用户点过“太频繁”或“认错了”的记录，单独标出来，不和策略跳过混在一起。
4. 现场数据由 D 独立计分，C 不给自己打分。
