# 0.7.0 监听中断恢复与锁屏验收

首页显示监听状态。系统报告麦克风静音、读取失败或连续 15 秒都读不到音频时，声境会停止监听并显示恢复提示。环境很安静时，麦克风仍可能返回有效采样。请按提示检查设备，再手动开始监听。

在「诊断与测试工具」查看「最近一次监听」。页面显示启动后的时长、已完成的声音处理窗口数、最后一次完成窗口的时间和相邻处理结果的最长间隔。它们可用来排查处理停顿。手表是否收到提醒仍由佩戴者确认。

应用只保留最近一次监听的汇总数字和结束状态。首个处理结果、随后约每 30 秒的进度和结束状态写入本机。进程突然退出后，重新打开显示「上次监听中断」和最近保存的进度，确切中断时间和原因可能未知。下一次开始监听会覆盖这份摘要。事件与反馈仍在原提醒记录页。

## 下一次集中真机验收

建议使用固定签名包覆盖安装。以下步骤待 Find X8 Pro 与 Watch X2 验证。

| 操作 | 观察 |
|---|---|
| 开始监听，在居家场景锁屏半小时，约第 2、10、30 分钟各敲一次房门 | 分别核对腕上提醒、手机对应记录。解锁后查看窗口数、最后一个窗口时间及最长间隔。 |
| 从通知点「停止」，然后重新打开应用 | 常驻监听通知消失，麦克风释放。摘要显示「已手动停止」，停止后的时长和数量固定。 |
| 开始监听后关闭系统麦克风开关 | 记录此机型返回的状态与所需时间；系统报告静音时应停听并显示恢复办法。开启开关后，手动开始监听，再敲门验证。 |
| 开始监听并运行至少 1 分钟，从系统应用详情强行停止，再重新打开 | 首页提示上次中断，麦克风保持关闭。先查看上次摘要，再开始新一轮。手动重试后计数从头开始。 |
