# 0.9.0 现场演示与锁屏操作

| 现场动作 | 手机与手表上应观察什么 |
|---|---|
| 首页进入「现场演示与锁屏核对」 | 检查麦克风、通知权限、已关注的声音、被关闭的类别通道和系统省电状态。按页面提示打开相应设置。 |
| 点「开始监听」，再点「开始新一轮」 | 保持居家场景，手机放到桌上，请队友敲真实房门。本轮从点击时开始计数。 |
| 在腕上查看并确认提醒 | 手机显示真实识别类别、系统通知请求和反馈数。佩戴者另在演示页报告本轮是否看到腕上提醒。 |
| 结束本轮，复制摘要 | 摘要冻结，可手动粘贴到团队验收记录。下次开始会替换上一轮。清空提醒记录会一并清除摘要。 |

演示只统计本机仍保留的最多 100 条提醒中的本轮记录。模拟提醒单列。腕上观察为本轮人工记录，实际敲击次数、漏提醒及到达延迟需另行实测。结束演示后，使用首页或常驻通知的「停止」释放麦克风。

## 一次真机验收

1. 进入手表设置引导，选择门铃，点「10 秒后发送，可先锁屏」。在腕上找到同名测试通知，再回手机手动确认。另试一次取消，等待十秒后核对没有新记录。
2. 启动监听，使用手机的常驻通知暂停真实提醒，观察暂停状态和麦克风占用。恢复提醒，再触发真实敲门。系统锁屏操作可能要求解锁。
3. 在一轮演示中做一次模拟提醒和一次真实敲门，比较两类计数。结束后再触发提醒，已复制的摘要应保持一致。
4. 完成 [半小时锁屏验收](listening-recovery.md) 及 [多条通知与腕上反馈](notification-journey.md)。进程异常退出后，重新打开应显示演示中断及保留结果。
