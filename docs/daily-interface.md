# 0.6.0 手机日常使用与设备引导

在首页点「开始监听」。首次使用时，按「设置权限与手表」页面提示开启麦克风和手机通知权限，返回首页后再开始监听。首页显示当前场景和最近提醒，点「查看提醒记录与反馈」可以确认或纠正记录。模拟事件在首页和记录中均有标记。

在手机配套健康应用中开启声境通知同步，然后在设备引导页点「发送手表测试提醒」。看到对应的手表通知后，点「我在手表上看到了」。首页保存这次手动确认的时间。以后断开蓝牙，这个时间仍表示上一次测试的结果。手机上的「已请求通知」只记录系统通知请求。

场景、关注类别和提醒间隔预览在「场景与提醒设置」。采集峰值、各通知通道和延迟模拟测试在「诊断与测试工具」。进入这些页面不会自动打开麦克风。

## 下次集中真机验收

0.5.1 已在 Find X8 Pro 和 Watch X2 上由佩戴者确认真实敲门和手表通知正常，未再出现兼容性弹窗。以下为 0.6.0 的待测项目。

| 项目 | 操作与观察 |
|---|---|
| 覆盖升级 | 检查原有场景、提醒记录和反馈仍在。停听状态打开首页，确认不会自行开始监听。 |
| 首次操作 | 请一位未用过声境的同学自行开始监听、找到最近一次提醒，再停止。记录卡住的按钮或词语。 |
| 权限与手表 | 停止监听后关闭一项权限，从首页开始，验证能找到开启入口。恢复权限，发送手表测试提醒，核对只有手动确认后才显示时间。 |
| 大字 | 系统字体调至最大，检查首页、设置及记录文字能换行，各页能滚动至最后一个按钮。 |
| 锁屏半小时 | 选择居家，开启敲门提醒并开始监听。锁屏后约第 2、10、30 分钟各敲一次同一扇门。分别记下实际敲门、手表到达情况与解锁后的手机记录。漏报时优先查看采集状态和通道设置。 |
| 停止 | 从首页停止监听，确认常驻监听通知消失、麦克风占用释放。再次敲门，记录应无新识别事件。 |

锁屏测试使用真实房门。诊断页的十秒延迟模拟只能检查通知同步。记录汇总结果即可，无需录音或导出设备日志。
